This module automates employee contract expiration notifications by sending email reminders to employees before their contracts expire.

Features:

* Automated email reminders for expiring contracts
* Configurable reminder days via system settings
* Daily cron job for batch reminder processing
* Customizable email template
* Integrates with HR contract version management
