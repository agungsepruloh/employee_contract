This module automates employee contract expiration notifications by sending email reminders to employees before their contracts expire.

Features:

* Automated email reminders for expiring contracts
* Configurable reminder days via system settings
* Daily cron job for batch reminder processing
* Customizable email template
* Integrates with HR contract version management

Usage
=====

#. Go to Settings > General Settings and scroll to the Employee section.
#. Configure the "Contract Expiration Reminder" setting with the number of days before expiration to send reminders.
#. Ensure outgoing email server is configured in Settings > Email > Outgoing Email Servers.
#. The cron job will automatically send reminder emails to employees whose contracts are expiring within the configured days.
